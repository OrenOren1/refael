# Semantic Versioning + Git Tags

## Context and Problem Statement

The assignment requires a version bumping strategy. The image tag and Helm chart version must be derivable from the git history.

## Decision Outcome

Chosen option: "Semver git tags (`v1.2.3`)", because they produce human-readable, sortable release identifiers. CI derives the image tag from the git tag. Manual tag push triggers the release pipeline.

**Workflow:**
1. Developer pushes `git tag v1.2.3 && git push origin v1.2.3`
2. `on: push: tags: ["v*"]` triggers the release pipeline
3. `IMAGE_TAG=$(git describe --tags --abbrev=0)` → ECR image tag
4. Helm chart `appVersion` updated to match

### Consequences

* Good, because semver communicates intent (breaking/feature/patch)
* Good, because `on: push: tags` decouples release from every commit push
* Bad, because requires manual tag discipline; no automated bump on merge
