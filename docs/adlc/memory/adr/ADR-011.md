# Terraform for AWS Infrastructure Provisioning

## Context and Problem Statement

AWS resources required before the pipeline and cluster run — ECR, GitHub OIDC trust/IAM, and an EKS cluster + nodes — must be reproducible and version-controlled.

## Decision Outcome

Chosen option: "Minimal Terraform in `terraform/` directory", because it makes the infra reproducible, reviewable, and idempotent. Manual `terraform apply` before first pipeline run.

**Resources provisioned (current `terraform/main.tf`):**

| Resource | Purpose |
|----------|---------|
| `aws_ecr_repository.app` + lifecycle | Private registry for `sample-nodejs` images (scan-on-push, keep last 10) |
| `aws_iam_openid_connect_provider.github` | GitHub OIDC trust |
| `aws_iam_role.github_actions` + policies | CI role (repo-scoped assume): ECR push and Terraform plan-read permissions |
| `aws_iam_role.eks_cluster` + attachment | EKS control-plane role (`AmazonEKSClusterPolicy`) |
| `aws_eks_cluster.main` | EKS cluster (v1.31) in default-VPC subnets filtered to EKS-compatible AZs |
| `aws_iam_role.eks_node` + attachments | Node role (`AmazonEKSWorkerNodePolicy`, `AmazonEKS_CNI_Policy`, `AmazonEC2ContainerRegistryReadOnly`) |
| `aws_eks_node_group.main` | Managed node group (`t3.small` default, desired 2 / min 1 / max 3) |

**Not in Terraform (current state):** ACM certificates and Route53 records/DNS validation are not provisioned. VPC/subnets are discovered from the default VPC (not created). ArgoCD installation is out of scope. An earlier draft of this ADR mentioned ACM/Route53; the implemented scope is ECR + OIDC/IAM + EKS only. HTTPS/Ingress TLS termination and certificate provisioning are therefore not handled by this Terraform; the Helm chart's nginx Ingress defaults to HTTP (`ingress.tls.enabled=false`, placeholder host).

### Consequences

* Good, because `terraform plan` shows exactly what changes before apply
* Good, because OIDC eliminates long-lived AWS credentials in GitHub secrets
* Good, because cluster and registry foundations are reproducible in code
* Bad, because requires AWS credentials locally to run `terraform apply`
* Bad, because HTTPS certificate/DNS automation (ACM/Route53) and ArgoCD bootstrap remain manual/out-of-scope

### Confirmation

`terraform/` directory with `main.tf`, `variables.tf`, `outputs.tf`. Outputs include ECR URL, GitHub Actions role ARN, cluster name/endpoint, and kubeconfig command. `AWS_ROLE_TO_ASSUME` secret is set from the role ARN.

## Constitution Alignment

| Principle | Alignment | Notes |
|-----------|-----------|-------|
| Security by Default (§4) | ✅ | OIDC, no long-lived keys; least-privilege IAM |
